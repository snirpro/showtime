About the Project

This application was developed as part of a Junior Software Developer assignment. The goal is to build an intuitive and complete solution that allows users to search for TV shows, explore detailed information, and interact with real-time data from the TVmaze API.

What You Can Do

  • Search for TV shows by name
  • Filter results by Genre, Rating, and Language
  • View detailed information about each show
  • Explore episode lists for every show

Technical Overview

Frontend: Angular

Backend: Node.JS

API: TVmaze REST API
