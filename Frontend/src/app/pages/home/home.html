About the Project

The goal of this project is to build an intuitive and complete solution that allows users to search for TV shows, explore detailed information, and interact with real-time data from the TVmaze API.

Note: This project uses a free Render backend, so the server may take up to 1-2 minutes to wake up on the first request.

What You Can Do

  • Search for TV shows by name
  • Filter results by Genre, Rating, and Language
  • View detailed information about each show
  • Explore episode lists for every show

Technical Overview

Frontend: Angular (hosted on GitHub Pages)

Backend: Node.JS (on Render)

API: TVmaze REST API
